# Orrery

An interactive 3D tour of the solar system, built with Next.js and React Three Fiber.
Scroll to fly outward from the Sun, planet by planet, or switch to Explore mode and
orbit, zoom and click your way around the system.

Every surface is procedural: the Sun, the planets, the Moon, Saturn's rings and the
asteroid belt are all generated by GLSL shaders at runtime. There are no textures to
download.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Other scripts:

```bash
npm run build      # production build
npm start          # serve the production build
npm test           # unit tests (Vitest)
npm run lint       # ESLint
npm run typecheck  # TypeScript
```

## How it works

- `src/data/bodies.ts` is the single source of truth: copy, stats, orbit and rotation
  parameters, palettes and shader settings for every body.
- `src/lib/` holds the pure logic (orbit positions, scroll-to-tour mapping, camera
  framing, quality tiers, seeded randomness). All of it is unit-tested in `tests/`.
- `src/components/scene/` is the 3D layer. One fixed full-screen canvas sits behind the
  page. The camera rig follows the scroll position in tour mode and hands the camera to
  camera-controls in Explore mode.
- `src/shaders/` contains the GLSL for the star, the planet families (rocky, Earth,
  Venus, gas giant, ice giant), atmospheres, rings, the star dome, nebula, dust and the
  instanced asteroid belt.
- `src/components/ui/` is the DOM layer: hero, story panels, progress rail, explore HUD,
  loader.

## Controls

Tour mode: scroll, or use the rail on the right to jump between worlds. Click any world
to visit it.

Explore mode: drag to orbit, scroll or pinch to zoom, click a world to fly to it. Use the
dock at the bottom or the left and right arrow keys to move between worlds. Escape or
"Back to the tour" returns you to the scroll journey.

## Quality and accessibility

The scene picks a quality tier on load from the device's pointer type, core count and
memory. The tier controls post-processing, pixel ratio and particle counts. Reduced
motion is respected: the camera snaps between sections instead of flying, twinkling and
flare motion stop, and panel transitions become instant. Browsers without WebGL still
get the full text of the tour over a static sky.

Figures follow NASA planetary fact sheets. Distances and sizes in the 3D model are
compressed on purpose; nothing is to scale.
